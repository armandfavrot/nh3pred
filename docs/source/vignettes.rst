Vignettes
=========

The following vignettes use the installed ``nh3pred`` package. Their Quarto
sources are provided in ``docs/vignettes`` in the source distribution.
Prediction examples use synthetic inputs only. Interpretation plots are
precomputed summaries of research data, which are not distributed.

* `Getting started <_static/vignettes/getting_started.html>`_
* `Input reference <_static/vignettes/input_reference.html>`_
* `Scenario comparison <_static/vignettes/scenario_comparison.html>`_
* `Model and interpretation <_static/vignettes/model_description.html>`_
* `Combined PDF <_static/vignettes/ammonia_emissions_vignettes.pdf>`_

Run ``python docs/render_vignettes.py`` after installing the documentation
dependencies, Quarto and a LaTeX distribution. This executes the prediction
examples and builds HTML and a combined PDF without access to research data.
Recomputing the interpretation plots requires the separate research project.
